# 36 Monday Moves | Interactive Teacher Playbook

EL Publishing · Richard Daniel · *Open it. Say it. Teach it.*

An interactive version of the 36 Monday Moves teacher binder for content teachers of English learners (grades 6–12):

- **Year map** of 36 moves across six strands, with search, strand filters, and an "If you notice…" need finder
- **Teach it in 3 steps** guides (SHOW → TRY → CHECK) with a built-in 5-minute step timer and read-aloud SAY lines
- **Cartoon practice missions** with instant A/B feedback, fillable sentence frames, and a covered teacher strip
- **Project mode** for full-screen classroom display with the answer hidden
- **Planning tools**, flip-style desk cards, a growth check, and a 36-move implementation tracker
- **Evidence map** linking each move to IES What Works Clearinghouse practice guides

Everything is in a single self-contained `index.html`. Notes and checkmarks save in the viewer's own browser (localStorage).
